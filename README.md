# BARBER CLUB - WebApp de Reservas

Plataforma fullstack de reservas para barberías con panel de control integrado. Desarrollada con React, Vite y Tailwind CSS.

## Características
- ✂️ Selector de servicios, horarios y fechas.
- 📱 Panel de barberos en tiempo real para control de turnos.
- 💸 100% gratuita ($0 de costo operativo).
